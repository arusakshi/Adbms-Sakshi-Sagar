# 🔎 Python TCP Port Scanner

A small educational cybersecurity project that checks TCP ports **1–1024** on a host and reports ports that accept connections.

## Features
- Python socket programming
- TCP connectivity checks
- Basic service-name lookup
- Connection timeout handling
- Simple command-line interface

## Run

```bash
python port_scanner.py 127.0.0.1
```

Use this tool only against **your own systems or systems for which you have explicit permission to test**.

## Skills Demonstrated

Python • Networking • TCP/IP • Socket Programming • Basic Reconnaissance
